# ⚠️ ไฟล์เหล่านี้ไม่ได้ใช้กับโปรเจกต์จริง

ไฟล์ 3 ไฟล์ในโฟลเดอร์นี้ (01_schema.sql, 02_scoring_functions.sql, 03_admin_functions.sql)
คือดีไซน์ตั้งต้นที่ออกแบบไว้ก่อนจะทราบว่า Supabase project "KPOR" มีฐานข้อมูลที่ใช้งานจริงอยู่แล้ว
(ตาราง categories/exam_years/questions ที่มีข้อมูลจริง 117+ ข้อ)

**ห้ามรันไฟล์เหล่านี้กับโปรเจกต์ KPOR จริง** เพราะ schema ไม่ตรงกัน (พยายามสร้างตาราง `questions`
ที่มีอยู่แล้วซ้ำ จะ error หรือขัดแย้งกับโครงสร้างเดิม)

เก็บไว้เป็นข้อมูลอ้างอิงเผื่อทำโปรเจกต์ใหม่แยกต่างหากในอนาคตเท่านั้น
ไฟล์ที่ใช้งานจริงคือ `../04_adapt_existing_schema.sql` (ได้รันเข้า Supabase project จริงเรียบร้อยแล้ว)
